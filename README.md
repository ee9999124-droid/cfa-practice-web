# Arc · CFA Practice

不需伺服器的 local-first CFA 刷題工具，可直接部署至 GitHub Pages。題庫、Word 原作答匯入紀錄、網站作答紀錄與未完成練習只保存在本工具專用的瀏覽器 IndexedDB。

## 重要：實際 Word 樣本仍待提供

此儲存庫與目前工作環境**沒有實際官方 Word 樣本**，因此不能宣稱已逐題核對官方 Word。請透過私密方式提供實際 `.docx`，不要將官方題目、答案、詳解或樣本提交到公開儲存庫。取得樣本後，應在「匯入預覽」逐題核對，再確認匯入。

目前解析器以結構標記切分資料，而不是用百分比或零散關鍵字猜題：

- 只接受標示為 `Multiple Choice` 的題目；Numeric Entry、Fill、Text Response、Essay 會列在排除清單。
- `Quiz review`、分數及平均時間摘要會排除，但題幹中的百分比和數字會保留。
- `Correct answer`、原作答標記、`Feedback` 及選取狀態是結構欄位，不混入題幹。
- 重複且完全相同的選項標籤會去重；同標籤不同內容會隔離為不可練習，不猜測或重新編號。
- 表格、圖片及文字 block 會保留在情境、題幹與詳解中。
- 有明確 `Vignette` 標記才自動判為題組；題目前有未標記內容則列為待確認。

## 匯入與試用步驟

1. 先至右上角「本機資料」按「清除全部測試資料」，確認後清除本工具資料。
2. 至「題庫」選擇 Word；先核對題組數、獨立題數、總題數、排除項目與原因。
3. 展開每組，逐題核對完整情境、題幹、選項、正確答案、Word 原作答及官方詳解。
4. 手動修正 Topic、Module、題目形式和正確答案。缺答案、選項衝突或形式待確認的內容不會進入練習。
5. 確認匯入。同內容 Word 再次匯入會先警告，確認後才取代。
6. 在「開始練習」選 Topic／Module 及形式。Vignette 永遠完整抽取；獨立題可精確依題數抽取。
7. 作答期間不顯示答案；按一次 Submit 後再統一顯示結果與官方詳解。
8. 在「統計」先看 Topic，展開檢視 Module。

## CI 題組對照表

匯入 Corporate Issuers（或檔名含 `CI`）文件時，解析器會依 **Word 原始題號**套用已核對的 Module 1–4 題組、獨立題及排除題對照表；排除題不會令後續題號位移。題組沿用第一題所屬的完整 Vignette（包含表格與圖片），獨立題不沿用 Vignette，但題目自己的內容仍完整保留。這是可擴充的資料式對照表，並不會清除或遷移既有題庫；請在題庫管理中自行移除舊 CI 後重新匯入。

`npm test` 使用程式產生的區塊測試逐組核對題號、Titian 共用情境、表格／圖片、排除及獨立題不夾帶情境。這只能驗證程式規則；repository **沒有原始 Word**，所以實際文件的段落結構、內容完整性及匯入預覽仍須拿原檔人工核對。
