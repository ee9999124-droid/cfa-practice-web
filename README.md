# Arc · CFA Practice

不需伺服器的 local-first CFA 刷題工具，可直接部署至 GitHub Pages。題庫、作答紀錄與未完成練習都保存在瀏覽器 IndexedDB。

## 題目形式

- **Vignette 題組**：Word 內有明確 `Vignette` 標記的共用情境；抽題時永遠保留完整題組。
- **獨立單題**：沒有共用情境的題目；可依目標題數逐題抽取。
- **待確認**：有疑似情境但缺少可靠標記，或是從舊版留下、尚未分類的項目。它不會被強行納入練習，可在「題庫」展開項目後手動更正，也可以重新匯入原 Word。

手動更正只更新題目形式。移除題庫會同步清除該題庫專屬的網站練習與 Word 匯入紀錄，因此操作前應先匯出備份；其他題庫的紀錄不受影響。備份 JSON 包含題庫、題目形式、歷史與草稿。

## 本機驗證

```bash
npm test
python3 -m http.server 4173
```

開啟 `http://localhost:4173`。專案只使用相對路徑與瀏覽器原生 API，沒有執行期套件或遠端 CSS import。

## 移除與重新匯入

移除題庫前建議先由右上角「備份」匯出完整 JSON。確認移除後，該題庫的 Word 匯入紀錄及網站練習紀錄會一併刪除；跨題庫練習只會移除屬於該題庫的部分，其他題庫的答案會保留並重新計算統計。

重新匯入同一份 Word 會視為全新題庫，不恢復已刪除的網站練習；Word 本身可可靠辨識的原作答仍會建立新的「Word 匯入紀錄」。為避免重複計入，尚未移除同一題庫時不能重複匯入。
